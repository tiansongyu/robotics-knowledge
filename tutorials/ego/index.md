# Ego 第一人称操作学习

一个人伸手打开盒盖。头戴相机拍到了指尖与盖沿接触的瞬间，桌旁的相机则看到了整条手臂和盒子的位置。要回答“盒盖什么时候开始动”，可以逐帧检查物体状态。要回答“此刻指尖在三维空间什么位置”，还需要相机几何与时间对应。**第一人称视觉**（egocentric vision）研究从行动者自身视角获得的观测。本课程围绕操作数据，用 Ego4D 和 Ego-Exo4D 分别讲解这两个问题。[Ego4D 手物交互任务](https://ego4d-data.org/docs/benchmarks/hands-and-objects/) · [Ego-Exo4D 数据概览](https://docs.ego-exo4d-data.org/overview/)

```{figure} figures/views.svg
:width: 100%
:alt: 同一次开盒动作的教学示意。佩戴者近看指尖和盒盖，桌旁固定相机还能看到头部和手臂。

两台相机观察同一动作，各自保留了另一视角中容易被遮挡的细节。开盒图是教学示意，读图时先确认相机固定在哪里。
```

## 用一个片段学四件事

| 章节 | 可以带走的结果 |
| --- | --- |
| [选择视角与数据单元](recordings.md) | 能在元数据中定位一个片段，说明该用哪部相机、哪种时间基准 |
| [逐帧标注手物交互](annotation.md) | 能给接触和状态变化分别选择证据帧，读懂事件标签与检测框 |
| [多视角几何与手姿](geometry.md) | 能把一个三维指尖点投回佩戴者图像，按误差现象排查坐标和同步 |
| [训练样本与机器人迁移](learning.md) | 能为识别、预测和机器人模仿选择不同的监督信号 |
| [计算实验与自测](lab.md) | 用帧号、像素和时间区间分别度量三种误差 |

读者只需了解视频由连续图像组成。涉及投影时会给出坐标系、公式和数值。官方字段在对应章节链接到数据说明。文中的片段编号、像素和测量值为教学设定，练习可以在没有数据集账号的情况下完成。
