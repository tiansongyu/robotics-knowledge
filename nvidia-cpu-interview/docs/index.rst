NVIDIA CPU 系统软件面试手册
==========================================

**Senior System Software Engineer, CPU · JR2025929 · 上海 / 深圳**

选一个你亲手排查过的机器人或车载系统故障，画出请求从软件到硬件、再返回软件的路径。你改了哪段代码？哪条证据让你改变了最初的判断？怎样证明修复有效？这个岗位为 Tegra / Vera 开发诊断软件，这三个问题能把 C/C++、体系结构、驱动和测试连成一次有说服力的面试回答。

岗位要求与准备深度
----------------------------

招聘说明要求电子工程或计算机科学本科或硕士、至少五年相关行业经验，同时强调 C/C++、操作系统与内核编程、计算机体系结构、近硬件 SoC 开发、排障、沟通和计划。工作覆盖驱动与测试的完整生命周期，也要与硬件、架构、软件团队以及客户和合作伙伴协作。大型模块化系统软件代码库经验属优先条件。Linux 内核内部机制、Arm 平台和诊断软件经验是官方单列的三项加分。下表的准备深度和各章练习是根据这些职责设计的自测。 `NVIDIA 官方职位说明 <https://nvidia.wd5.myworkdayjobs.com/en-US/NVIDIAExternalCareerSite/job/China-Shenzhen/Senior-System-Software-Engineer--CPU_JR2025929>`_

怎么用这本手册
----------------------------

* **约谈前**，先看 :doc:`experience` 。从机器人或自动驾驶经历中选一个真正动过代码的案例，准备 90 秒概述，再列出要向 Echo 确认的事。
* **准备技术面**，先做 :doc:`drivers` 的白板题和 :doc:`diagnostics` 的 C 练习。哪一步说不清楚，就回到对应基础章。阅读需要熟悉 C 函数和一般 Linux 命令，运行练习需要 C11 编译器。
* **安排复习**，按“能解释原理、能独立写或画、能用证据定位并验证修复”三级给每项技能自评。优先复习岗位明确要求、而自己暂时只能解释的项目。最后用 :doc:`experience` 的七天安排做一次完整演练。
