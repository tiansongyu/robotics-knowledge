C/C++ 系统编程
==========================================

一份设备完成记录只有若干字节。设备规定字段偏移、字节序和有效位，编译器则按语言与 ABI 规则排列对象。试着从这两套约束推导出可测试的 C/C++ 代码。

需要掌握
----------------------------

* **C 的数据表示。** 固定宽度整数、符号扩展、移位与掩码、整数提升、长度加法和乘法的溢出、字节序、结构体填充、对齐与别名。给出一个字节数组，能按协议取出字段，并说明为何不能随意把地址转成结构体指针。
* **指针与寿命。** 区分栈、静态存储和动态分配。能沿成功、部分初始化失败、取消和关闭四条路径找出所有者。熟悉函数指针、回调上下文、引用计数、链表、位图和环形队列。能给出所选结构的时间与空间成本。
* **C++ 资源管理。** 用 RAII 封装文件描述符或主机端缓冲区，用移动语义转移唯一所有权。解释拷贝策略、析构顺序、容器扩容导致的引用失效以及跨线程访问的生命周期约束。Linux 内核驱动通常用 C，主机端诊断程序可以用 C++ 演练这些问题。 `C++ Core Guidelines 资源管理章节 <https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#S-resource>`_
* **并发语义。** 区分互斥、原子性与操作顺序。以普通 RAM 中的单次发布为例，一个线程先写负载，再以 release 写就绪标志。另一线程用 acquire 读到该次发布后才读负载。复用缓冲区时还要约定归还所有权的时机。设备寄存器访问要按平台 I/O 接口处理。 `Arm 的线程同步示例 <https://learn.arm.com/learning-paths/servers-and-cloud-computing/memory_consistency/examples/>`_
* **构建与符号。** 理解声明与定义、编译与链接、符号可见性、调试信息、优化级别。能用编译器警告或 sanitizer 检查用户态程序，再用带符号的二进制核对栈帧。

白板练习
----------------------------

**给定长度为 n 的字节数组，从偏移 off 读取四字节小端整数。如何处理最后三个字节和极大的 off？**

先检查输出位置和输入指针符合接口契约，检查 off ≤ n，再检查 n − off ≥ 4。逐字节组装前把各字节提升为 uint32_t，或使用适合目标环境的无对齐小端读取接口。测试刚好四字节、最后三个字节、空数组、极大偏移和最高字节为 0x80 的输入。把协议格式同 CPU 本机字节序分别说明。

**一个类拥有文件描述符。两个对象复制后分别析构会怎样？**

默认浅拷贝可能使两个对象都关闭同一个编号。若编号已被系统复用，还可能关闭其他资源。按接口需求设计成唯一所有者并支持移动，或显式复制描述符并处理失败。用移动后析构、初始化失败和重复清理检验约定。

**环形队列怎样区分空与满？**

声明容量、索引含义与并发模型。保留一个空槽会减少一个可用位置，单调计数器方案则要说明回绕假设。先写单线程边界测试，再讨论单生产者、单消费者对索引的发布顺序。多个生产者会改变同步条件。
